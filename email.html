How to Get App Password

For Gmail Users:

1. Go to Google Account → Security → 2-Step Verification

2. Enable 2-Step Verification if not already enabled

3. Under "App passwords", select "Mail" and "Other"

4. Generate 16-character password and use it here

For Outlook/Hotmail Users:

1. Go to Microsoft Account Security → Advanced security options

2. Create a new app password under "App passwords"

3. Generate password and use it here

For Yahoo Users:

1. Go to Yahoo Account Security → Generate app password

2. Create a new app password for "Mail"

3. Generate password and use it here
